Apex Kill Zone Engine API

Public, read-only JSON API endpoints for trade-level analysis and simulation.

Version 1.0 CORS Enabled

Endpoints

All endpoints are GET-only and publicly accessible cross-origin (Access-Control-Allow-Origin: *).

Method Endpoint URL Description
GET /api/trades.json Full dataset of all individual trade executions, outcomes, and exact realized R values.

Direct URL: https://meegol.github.io/apex-killzone-engine/api/trades.json

Key Parameters & Conventions

  • Timestamps: ISO 8601 formatted in UTC (e.g. 2026-06-02T13:50:00Z).
  • Date Format: ISO 8601 calendar date (YYYY-MM-DD).
  • Realized R (realized_r): Numeric unrounded R outcome for Monte Carlo, drawdown, and expectancy modeling.
    • 4.0 = Target hit (full 1:4 winner)
    • -1.0 = Stop loss hit (-1R loss)
    • 0.0 = Breakeven exit
    • Fractional floats (e.g. 1.693) = EOD exit or custom R exit
  • Ordering: Trades are returned in strictly chronological order (oldest → newest).
  • Filtering: As a static GitHub Pages endpoint, client-side query parameters (e.g., ?instrument=NQ=F&from=2026-06-01) are ignored by the host server; clients can filter the complete JSON payload in memory.
